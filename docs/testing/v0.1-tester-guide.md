# v0.1 tester guide

For the owner to send with the invitation (F4). The **feedback questions are a draft**: the PRD
says the owner writes them; edit them before sending. Answers are collected privately (the owner
keeps them in `.private/feedback/v0.1.md`, not in this repository).

## Before you start (10 minutes)

1. Install OmniOrchestrator from the release link you were sent.
2. Open it. If the app says it did not find the tools you need, choose **Yes, guide me**; the Setup
   guide walks you through Git and an AI coding tool.
3. In **Settings**, set up a model: your own API key, or a free local model (the app explains both).

## What to try (about one hour)

1. **Start from an idea.** Describe something you would like built. Answer the AI's questions until
   it says it has understood, then name the project and start the phases.
2. **Planning.** For each phase, read the document. If it asks you something, answer in the
   conversation under it and press **Generate final document**. Approve it, or request changes.
3. **Tools.** After the architecture, choose the AI tools you use and the models you use in each.
   Approve the task list (it says which tool and model does each task, and why).
4. **Build.** Press **Set up and open all**, follow the steps shown for each tool, and let one tool do
   its first task. Then open a different tool and check it knows where the project stands without
   you explaining.
5. **Skills (optional).** In Skills, add a skill of your own or switch one off.

## Draft feedback questions (owner: edit before sending)

1. Were you technical before this (have you used Git, an editor, an AI coding tool)?
2. Setup: where did you get stuck, if anywhere? How long did it take?
3. The conversation at the start: did the AI understand your idea? How many messages did it take?
4. Planning: was any phase confusing or too slow? Did you read the documents, or approve without
   reading? Why?
5. Tools and tasks: did the split of tasks between your tools make sense?
6. Switching tools: did the second tool know where the project stood without you explaining?
7. What did you expect the app to do that it did not?
8. Anything that looked broken, wrong or untrustworthy? (What you did, expected, and saw.)
9. Would you use it for a real project? What would have to change first?
10. On a scale of 1-10, how likely are you to recommend it to someone who builds with AI tools?

Please do not include API keys or private project content in your answers.
