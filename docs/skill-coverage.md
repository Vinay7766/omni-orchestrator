## Gaps

- desktop-apps: Desktop app packaging, code signing, installers and updates
- incident-response: On-call, incident handling, postmortems, capacity planning (SRE)
- compliance-privacy: Privacy law, audits, licence compliance
- ux-research: User research, wireframes, usability testing
- accessibility: Accessibility audits and testing (WCAG conformance checks)
- end-to-end-and-load-testing: End-to-end test strategy, load and stress testing
- product-analytics: Measuring product use: events, funnels, experiments
- sales-enablement: Sales material, demos, objection handling
- cost-economics: Cost estimates, cloud cost, build-versus-buy (SWEBOK: software engineering economics)
- stack-selection: Choosing a tech stack from the project's constraints, recorded as an ADR (STK)
- adversarial-security: Red-team / blue-team passes on the project itself (SEC)
- low-level-design: Class and sequence design, design patterns, module internals (LLD)
- algorithms-data-structures: Choosing and implementing algorithms and data structures (SWEBOK: computing foundations)
- networking: Protocols, sockets, HTTP, latency and offline behaviour
- i18n-l10n: Internationalisation and localisation: languages, formats, right-to-left text
- software-maintenance: Maintaining and evolving existing and legacy code (SWEBOK: software maintenance)
- configuration-management: Versions, baselines, environments and configuration (SWEBOK: configuration management)
- payments: Taking payments safely: providers, webhooks, refunds, compliance basics

## Notes

- cloud: Azure: Microsoft's official azure-deploy skill only works together with azure-prepare and azure-validate (about 200 files), so it is not bundled yet.
- app-distribution: Apple App Store covered (asc skills, which need the unofficial asc CLI and the person's App Store Connect API key). Google Play: no vetted skill yet; Google's play-policy-insights depends on its Python scripts, including a store scraper.
