## Notes

- cloud: Azure: Microsoft's official azure-deploy skill only works together with azure-prepare and azure-validate (about 200 files), so it is not bundled yet.
- app-distribution: Apple App Store covered (asc skills, which need the unofficial asc CLI and the person's App Store Connect API key). Google Play: no vetted skill yet; Google's play-policy-insights depends on its Python scripts, including a store scraper.
- incident-response: Incident handling, status updates and blameless postmortems covered. System capacity planning: no vetted skill yet (Anthropic's capacity-plan is about team capacity, not systems).
- compliance-privacy: compliance-check covers GDPR, CCPA/CPRA and other privacy laws but not India's Digital Personal Data Protection Act 2023. Licence compliance: no dedicated skill yet.
- end-to-end-and-load-testing: Load, stress and functional checks covered by k6. Microsoft's playwright-cli is not bundled: its end-to-end test generation and test running live in reference files that would not ship, and it overlaps browser-testing-with-devtools.
- cost-economics: Vendor total cost of ownership (vendor-review) and AWS cost (aws-billing-and-cost-management) covered. Build-versus-buy for in-house work and other clouds: no vetted skill yet.
- algorithms-data-structures: Partly covered: solution-design makes the agent name the problem class and derive time and space complexity before choosing an approach. No vetted skill teaches specific algorithms or data structures.
- networking: No vetted skill yet: the skills found under this name were career-networking or single-project files from unknown authors.
- i18n-l10n: No vetted skill yet. FormatJS's localization-review was the best candidate, but its repository has no license file, so it cannot be bundled. swiftui-expert-skill covers localization for Apple platforms only.
- configuration-management: Versions, release tags and changelogs covered by git-workflow-and-versioning. Environment and runtime configuration management: no vetted skill yet.
- payments: Stripe covered by Stripe's own skill. Provider-neutral PCI DSS guidance: no vetted skill yet (wshobson's pci-compliance was rejected because its examples use Stripe's legacy Charges API and a hard-coded global API key).
