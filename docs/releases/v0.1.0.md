# OmniOrchestrator v0.1.0 (Foundation): notes for private testers

Thank you for testing. This is an early, private version: it works end to end, and it will have
rough edges. Please read **Known limits** first.

## What to expect

You start from an idea in the app and talk it through with your own AI model. The app then runs
the planning phases one by one (idea review, research, PRD, architecture and the task list), and
**you approve each one**. After the architecture you choose the AI tools you use and the models in
each; each task goes to the tool and model that fit it best, and the app hands the build to them.
Every tool reads and writes one shared project memory (the `.agents/` folder in your project), so
you can switch tools and the next one carries on.

What was proven before this release, and what is only tested automatically so far, is listed in
the README under "What works today".

## Known limits

- **Approvals can be forged** by a program running as you (for example an AI tool writing the
  memory files directly); this is not detected yet. Tamper-evident approvals come in a later version.
- **Installers are not code-signed.** Windows SmartScreen and macOS Gatekeeper will warn you; on
  macOS, right-click the app and choose Open the first time.
- **Connecting an AI tool through MCP needs a copy of the repository** (`npm install`,
  `npm run build`); see docs/mcp-setup.md. Tools that read instruction files, or a chat you paste
  into, work without it.
- **The editor extension is not in a marketplace yet**; run it from the repository (README).
- **The look of the app is unfinished**; a redesign is planned.
- Planning asks your model for long answers; a model with a small output limit may refuse.

## Your data

Everything stays on your computer. The only network calls go to the AI provider you set up, with
the project text you ask it to work on. API keys are kept in your system's credential store.
Nothing is collected by OmniOrchestrator.

## Giving feedback

Use the questions in the tester guide your invitation came with. Please include what you did, what
you expected and what happened (a screenshot or the exact error text helps). Do not send API keys
or private project content.
